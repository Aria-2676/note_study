索引：本项目的强制规则（唯一来源）

这里是规则的**目录**，不是规则本身。规则条文只存在于本目录 `rule-*.md` 各卡中，
`CLAUDE.md` 与 `docs/decisions.md` 都不复述条文。

| 主题 | 文件 | 什么时候必须读 |
|---|---|---|
| Provider 状态管理 | `rule-1`（Provider） | 加/改 Provider、在 UI 里读 Provider 数据 |
| 统计埋点 | `rule-2`（统计） | 加埋点、改适配器、动统计缓存 |
| 工程结构与依赖方向 | `rule-3`（依赖方向） | 新建目录/模块、判断某逻辑该放 core 还是 modules |
| 编码、入口与异常 | `rule-4`（入口与异常） | 改 `main.dart`、写异步 I/O、解析外部数据 |
| 单元测试 | `rule-5`（测试） | 写测试、评估覆盖率 |
| 代码量控制 | `rule-6`（代码量） | 文件接近 300 行、需要拆分 |
| 提交、版本与兼容性 | `rule-7`（提交与版本） | 提交、对齐版本号、改 core 对外接口 |

引用规则时**只写主题名**（如「见规则：依赖方向」），**不要写 `rule-N` 编号** ——
编号会随规则增删重排而失效。

无法判断该读哪张卡时，按「我要改什么」在上面「什么时候必须读」一列里找，
找不到就读 `rule-3`（结构与依赖方向）——它定义了什么代码该放在哪里。
